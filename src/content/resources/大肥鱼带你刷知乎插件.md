让 AI 自己去刷知乎，然后把值得读的挑出来——这就是本站「资源 → 大肥鱼带你刷知乎」月报背后的那个插件，现在**开源**了。

它按你选的领域、来源和判断权重去读回答正文，挑出真正值得的那几条，攒成一本月度文章。原则很简单：**只读，不互动**——不点赞、不评论、不关注、不私信。

## 链接

> https://github.com/BacheLor11/dsh-zhihu-scroll

MIT 协议，源码、可安装的 `.tgz` 包、更新日志都在仓库里。

## 功能

| 能力 | 说明 |
| --- | --- |
| **按来源权重捞候选** | 推荐流 / 热榜 / 关注动态 / 关注的人，按 0–5 的权重比例分配每轮候选名额；「关注的人」会主动去翻关注列表里最近发的回答与文章，也可以在偏好里手动指定账号 |
| **按领域权重排序** | 16 个内置领域（人工智能、科技互联网、科学、商业财经、心理、历史、文化、职场、生活、教育、健康、游戏、影视、体育、汽车、理财），每个 0–5，命中多个领域加权求和 |
| **按判断权重筛** | 信息密度 / 时效 / 实操 / 观点多元，四个 0–5 的口径交给值班编辑，决定它挑什么、以及怎么写「为什么值得」 |
| **逐条读正文再判断** | 读回答全文、文章全文、问题下前 3 条高赞回答；接口只给得到摘要时会明确标注「只读到摘要」，不假装读完了 |
| **同问题一起看** | 读回答时顺手带出同问题下其他高赞回答，主条目下方附「同问题下还有」小列表（最多 3 条，不占每天额度） |
| **写月度文章** | 一个月一篇 `out/大肥鱼带你刷知乎YYYY年M月.md`，每天一个日期分区、最新一天排最前，分「必读 / 值得 / 一乐」三档，每条含「为什么值得」+ 一句原文摘录 |
| **定时值班** | 支持精确时间点（如 `08:30, 21:00`）或午间 12–14 / 夜间 18–24 窗口，一个窗口一天只跑一次，今天挑满上限就不再跑 |
| **聊天里直接用** | 工具全局注册，在任意对话里说一句「刷一轮知乎」就行 |

## 它不做什么

- **不做任何互动**：不点赞、不评论、不关注、不私信、不改资料——这一版不注册任何写操作工具；
- **不绕过风控**：碰上验证页 / 限流就停手，并如实区分「未登录 401」「风控验证页 403」「限流 429」，不会假装成功；
- **不替你做判断**：投资、医疗、法律类内容最多归到「一乐」，并注明「作者观点」；
- **不需要额外环境**：不用 Python、不用 `uv`、不用下模型。

## 安装

前置：DeepSeek Harness **≥ 0.2.1-rc.2**，以及一个能正常登录知乎的浏览器。

用打包好的 tgz 安装（推荐）：

```bash
dsh plugin --profile desktop add ./dsh-zhihu-scroll-0.3.2.tgz
```

或者直接从本地源码目录装（开发版，pnpm 会做软链，别移动删掉源目录）：

```bash
dsh plugin --profile desktop add <本仓库路径>
```

装完**重启一次 DSH**（bundle 层要重启才组装），然后进 **设置 → 刷知乎**。用 web profile 的话把 `desktop` 换成 `web`。

## 第一次用

**1. 登录（账号页）**

1. 浏览器打开知乎并确认已登录；
2. `F12` → **Network**，随便点一条 `zhihu.com/api/...` 请求 → 右键 → **Copy → Copy as cURL**；
3. 回到 **设置 → 刷知乎 → 账号**，点 **从剪贴板导入**（浏览器没给剪贴板权限就展开「手动粘贴 cURL / Cookie」整段粘进去）；
4. 点 **测一下**，会逐项测热榜、推荐流、关注动态、关注列表、正文接口，哪条没通、下一步该做什么，页面上都写着。

> 为什么不做扫码 / 短信登录：知乎对非浏览器客户端的登录轮询风控很严（实测扫码状态接口直接 403），而 cURL 里的登录态最直接、最稳，也不需要插件碰你的账号密码。

**2. 调偏好（偏好页）**

- **领域权重**：5 = 非常想看，0 = 不关心；
- **来源权重**：决定每轮名额，想看熟人就调高「关注动态 / 关注的人」；
- **判断权重**：决定它挑什么、怎么解释；
- **关注的人 / 额外关键词 / 人设**：留空即用关注列表；人设只借语气，不借事实。

保存后下一轮生效，不用重启。

**3. 跑一轮**

手动：在任意对话里说「刷一轮知乎」。定时：打开一个专门刷知乎的对话，在 **自动值班 → 定时投到** 里选中它，点「测试投递」确认能回 OK，再打开开关。定时任务只投到你选中的那个对话，不碰你正在聊的天。

## 数据与隐私

所有数据都在本机 `$DSH_HOME/zhihu-duty/`（`~/.dsh/zhihu-duty/`），路径可以在高级页里改，换目录时会把配置、Cookie、月度文章一起复制过去，不覆盖已有同名文件。

- Cookie 存在 `auth.json`（权限 `0600`），**不回显、不上传、不写日志**；
- 只请求 `www.zhihu.com`，不发往任何第三方；
- 设置页接口只接受本机同源请求（`127.0.0.1` / `localhost` / `[::1]`）；
- `auth.json` 里是登录态，**别放在网盘同步目录或公开目录**。
